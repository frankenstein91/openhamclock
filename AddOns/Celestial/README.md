# Celestial AddOn for OpenHamClock

A specialized userscript for tracking astronomical and celestial data (Sun, Moon, Planets, etc.) relevant for radio operations.

**Primary Purpose:** Helping operators aim Yagi antennas accurately towards celestial bodies (Solar tracking, etc.).

## Technical Foundation
This AddOn is planned to be built upon the **[d3-celestial](https://github.com/ofrohn/d3-celestial)** library for celestial map visualizations.

## Goals
- [ ] **Real-time Azimuth & Elevation display** for chosen celestial bodies.
- [ ] Integration of d3-celestial for star charts and visual tracking.
- [ ] Visualizing current positions of celestial bodies.
- [ ] Integration into the shared AddOn Drawer.
- [ ] Satellite pass predictions.

## Development
This AddOn uses the enhanced shared drawer system.

### How to use
1. Install a userscript manager like Tampermonkey.
2. Load `celestial.user.js`.
3. The ✨ icon will appear in the shared drawer.
